# Waar ga je mee naar huis?

- Je eigen project op GitHub
- Een ontwerpdocument: wat je maakt, en welke keuzes je maakte
- Een eerste lijst taken om verder aan te werken

<Callout title="Geen programmeerervaring nodig">Je AI schrijft de code. Jij leert hoe je het project goed opzet.</Callout>

# Wat mag je verwachten?

- We wisselen af: korte uitleg, en dan zelf doen
- Je AI schrijft de code, jij beslist wat er gemaakt wordt
- Soms gaat er iets mis. Dat hoort erbij: je blijft gewoon praten met je AI

<Callout title="Vandaag is een start">Je project is vandaag niet af. Wel kan je er na vandaag zelfstandig mee verder.</Callout>

# Wie heeft al een idee?

- Weet je al wat je wil maken? Steek je hand op.
- Hou het klein: wat is het kleinste dat al nuttig is?
- Nog geen idee? Denk aan iets dat je nu veel tijd kost, in de les of bij het voorbereiden.

<Callout title="Een voorbeeld">Deze demo-app over geluidsgolven, voor fysica, is gemaakt zoals in deze workshop: <a href="https://yvanvds.github.io/calculate-waveforms/" target="_blank">yvanvds.github.io/calculate-waveforms</a></Callout>
